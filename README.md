# Windows 实时翻译

一个 C# / WPF 的 Windows 桌面实时翻译工具，可以从屏幕字幕或电脑正在播放的声音中识别内容，并把最新译文显示在一个独立小窗口中。

## 环境要求

- Windows 10 或 Windows 11 x64
- .NET 10 SDK（开发、编译）
- 屏幕文字模式：Windows 自带的 OCR 语言包（进入“设置 > 时间和语言 > 语言”，为需要的语言勾选“手写/文字识别”）
- 电脑声音模式：有正常输出的扬声器或耳机，且在线语音服务可用

## 编译和运行

```powershell
cd F:\translation
dotnet restore
dotnet build
dotnet run --project RealtimeTranslator.csproj
```

编译产物位于：

```text
F:\translation\bin\Debug\net10.0-windows10.0.19041.0\RealtimeTranslator.exe
```

## 首次使用

1. 在主窗口选择“屏幕文字”或“电脑声音”，一次只运行一种。
2. 选择目标译文语言。
3. 屏幕文字模式下点击“框选字幕区域”，在屏幕上拖动选中视频字幕所在的固定区域。
4. 在“设置”页配置翻译服务和语音识别服务。
5. 点击“开始”。

点击主窗口右上角的关闭按钮不会退出程序，而是最小化到系统托盘。在托盘图标上双击可重新打开主窗口；托盘右键菜单可继续或退出。

## 在线服务配置

所有密钥都在程序“设置”页输入，不写入源码。设置文件位于：

```text
%APPDATA%\RealtimeTranslator\settings.json
```

保存到文件中的密钥使用当前 Windows 用户的 DPAPI 加密，同一账户下读取。

### 翻译服务

界面支持以下服务商，源语言由服务自动判断：

- OpenAI / OpenAI 兼容接口：填写接口地址、模型和 API 密钥。
- Microsoft Azure Translator：填写订阅密钥和区域（区域可留空）。
- DeepL：填写 API 密钥。
- Google Cloud Translation：填写 API 密钥。

### 电脑声音识别

第一版通过 Deepgram 流式 WebSocket 接口识别电脑声音。需要：

1. 到 [Deepgram](https://deepgram.com) 获取 API Key。
2. 在“电脑声音识别”中填写 Deepgram API 密钥。
3. 可按需修改接口地址、模型或语音语言；`auto` 表示由服务自动判断。

## 使用说明

- “开始/暂停”按钮可以随时暂停和继续。
- “重新框选”可随时更换屏幕识别区域，视频窗口移动后建议重新框选。
- 最新译文显示在“实时译文”独立窗口中；该窗口可拖动、调整大小、置顶、调透明度。
- “设置 > 历史与译文窗口”可调整置顶、透明度和历史保留条数。
- “设置 > 快捷键”可修改全局快捷键，默认值：
  - 开始 / 暂停：`Ctrl+Alt+T`
  - 重新框选区域：`Ctrl+Alt+R`
- 历史记录保留最近若干句（默认 10 条），支持清空、复制当前句、复制选中句和导出。
- 导出文件为 UTF-8 纯文本，每行格式为 `序号<TAB>时间<TAB>原文<TAB>译文`。
- “开机自动启动”会写入当前用户的启动项，可在设置页关闭。

## 实现说明

- 屏幕区域截取使用 Windows GDI 截屏，只对用户框选的固定区域取图；区域不随视频窗口移动。
- OCR 使用 Windows 自带的 `Windows.Media.Ocr`，同一句字幕未变化时不重复进入翻译。
- 屏幕识别结果和声音识别结果共用同一套去重、翻译和最新结果处理逻辑；翻译请求失败或超时只影响当前句，不阻塞后续字幕。
- 电脑声音使用 WASAPI 回环采集，只采集系统正在播放的声音，不打开麦克风。
- 语音识别使用流式 WebSocket，不需要等整段音频结束。
- 翻译服务、语音服务和屏幕采集均做了接口或组件隔离，后续可替换实现。

## 已知边界

- 受 DRM、播放器或系统安全策略保护的画面和声音可能无法采集，程序会提示失败而不会崩溃。
- OCR 和语音识别的准确率取决于系统 OCR 语言包及在线服务。
- 视频区域变化后需要重新框选；翻译窗口只显示最新一句，不做旧字幕积压补翻。
- 多人对话、音乐和复杂环境音不保证翻译效果，主要面向单人旁白类内容。

## 主要目录

```text
Capture/          屏幕区域截取、OCR、系统声音回环
Recognition/      流式语音识别客户端
Translation/      在线翻译服务接口与实现
Pipeline/         最新结果、去重、翻译协调
Configuration/    本地设置读取与保存
Services/         历史、全局快捷键、开机自启
UI/               区域框选窗口
```
